Entry for the make.fun competition **The Internet in One Word**
(`u-ronigrv-the-internet-in-one-word-e388f33b`): describe the whole
internet in a single word, judged head-to-head by a model weighing how
funny the word is, how well it fits the internet as a whole, and how
surprising it is.

## The word

> feral

(5 characters — one word, no setup, no explanation.)

Why this word wins: it makes a reader laugh and then nod — the internet
*is* feral. Wild, untamed, and it bites back: comment sections, memes,
scams, fandoms, drama, hot takes, all of it, with no leash on any of it.
It fits the whole internet, not one corner of it, and it is not the first
obvious word anyone reaches for (that would be "chaos", "memes", or
"doomscrolling" — the words half the field will submit). Five bytes also
wins the exact-tie break: the smaller text places first.

## How to run

```sh
python3 main.py
```

This writes the word to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default
`/output/entry.txt`), verifies the file content matches the word exactly,
checks the 1–30 character gate and that it is a single word with no
spaces or newline, and prints the word.
